# 第三方节点名称：本地前端预览

Risk: B. Process: one local frontend slice. Expected PR count: 1 at most.
Validation: focused UI/model tests, Admin tests/build, server regression and browser inspection.
Production/AWS impact: none. Frontend surface: admin. identity_impact: false.

## 本次范围

提供原始名称、协议及对外显示名称的紧凑合成列表；支持搜索、协议筛选、
行内编辑、取消、恢复默认与重名/控制字符/长度校验。移除独立编辑副卡、统计区和
来源/默认名称等第二行说明，普通行高约 53px。仅在 React 内存保存，
刷新页面恢复合成初始数据。没有节点地址、凭证、真实订阅或真实账户。

每行提供纯图标删除按钮，点击后在本行从右向左滑出删除/取消，默认聚焦取消；
删除使用透明浅红背景、取消使用透明浅蓝背景，支持减少动态效果偏好。
确认后仅移除本地节点，不再显示独立确认大卡片。
取消或 Escape 保留编辑草稿，删除其他节点不影响当前草稿；删除正在编辑的节点会明确
提供丢弃未保存修改的辅助说明。确认期间禁用竞争编辑/删除操作，筛选改变即取消待删除，
避免隐藏行仍可被确认删除。

工具栏合并为一个“导入”按钮，弹窗提供文件导入与 HTTPS YAML 两种方式。
文件仅检查扩展名、非空及 64 KiB 上限，
不读取正文；地址仅作 HTTPS/域名形式检查，不请求、不验证 DNS 或 YAML 内容。
检查通过不代表导入成功，不新增节点；关闭或切换入口会清空输入。
真实导入、服务端安全抓取和保存仍需后续接线，不属于本次前端交互交付。

同一工具栏提供“保存”“启用”：仅保存不可变的内存列表快照并启用本地预览状态。
有未应用行草稿、待删除确认或空列表时不可保存/启用；列表必须先保存才能启用。
改名应用或删除后原快照不再有效，需要重新保存和启用；过滤列表不改变完整快照。
刷新恢复初始数据和未启用状态，没有持久化或后台发布。

运行 `npm run admin:node-names:preview`，打开
`http://127.0.0.1:4193/node-names-preview.html#/third-party-node-names-preview`。
专用开发服务器仅监听 loopback，不加载 .env，无 API 反代，API 请求统一拒绝。
独立预览入口要求开发模式、本机 hostname 和精确 hash；不修改正式 App 或其鉴权。
通过 DEV 条件动态加载，且 HTML 不属于正式构建入口，正式构建不包含演示界面和合成数据。

## 非目标

本前端预览不调用正式节点列表/改名 API、持久化、后台发布或上游刷新。
“应用到本地预览”不是保存到后台；预览的名称校验与样式是 UI 合同草案，尚不是
已经接通生产订阅渲染的承诺。2026-10-13 后续已补后端节点管理源码，合同见
[第三方节点管理后端](../../../../docs/THIRD_PARTY_NODE_MANAGEMENT.md)；
正式 UI 接线见下文同日后续；本地预览行为保持不变。后端不改变内部身份、地址、
凭证或计量，远程刷新仍关闭。

### 同日正式 Admin 会话接线

`#/admin/thirdPartyNodes` 是正式登录后的入口，使用 `ThirdPartyAdminWorkspace`，
不是此 README 前述的无网络演示页。它复用行内编辑、紧凑列表和滑出删除交互，
但保存、启用、停用和文件导入均由同源 Cookie API 确认后更新，不乐观显示成功。
正式导入弹窗支持文件上传并选择适用套餐，HTTPS抓取明确未开放。
开发预览仍不调用真实接口，不应向预览页输入真实配置。

会话失效退回登录；角色拒绝清空数据并禁写。保存冲突/超时后必须读取新状态，
不会自动重复请求；含未保存草稿的重新读取有确认。已启用来源先停用才能编辑，
文件导入默认停用。新页面懒加载且不能从 baseline preview 访问。
完整接口和权限边界见上述后端说明。本轮是本地源码接线，不是生产功能已启用。
