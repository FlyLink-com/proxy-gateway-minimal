## What Changed And Why

PR #238 added the repository-local channel subscription output draft review
layer. It converts safe runtime bridge evidence into baseline, canary, private,
and blocked subscription-output planning pools while keeping YAML generation
disabled, real subscription output unchanged, and activation approval absent.
It exposed the review through a protected Admin platform route and Admin
Overview panel.

PR #239 added the #233-#237 cadence report and moved the latest stage-report
pointer forward. The report identified the channel-system integration gap:
runtime evidence, protected review, subscription-output drafting, and
activation gates were still only partially connected.

PR #240 added the repository-local channel subscription activation readiness
gate. It composes the output draft and checks whether safe evidence has a
baseline pool, a canary output pool, no blocked candidates, and runtime canary
evidence advanced to the `subscription_output_activation_approval` gate. The
packet marks execution authority as `not_granted` and exposes no approval or
execution route.

PR #241 added the repository-local channel subscription activation handoff
packet. It packages readiness into operator-safe A-tier handoff material with
candidate counts, grouped candidates, source runbook, and
preflight/validation/rollback checklist keys. It remains advisory and does not
include approval text or any execution endpoint.

PR #242 added the repository-local channel subscription activation flow. It
links the output draft, activation readiness, and activation handoff into one
protected end-to-end review packet so the operator can inspect the channel
system state before any later A-tier subscription-output activation request.
