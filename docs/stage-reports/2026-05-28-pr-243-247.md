## What Changed And Why

PR #243 added the #238-#242 cadence report and recorded the then-current
channel-system integration gap: the repo had safe runtime evidence review,
subscription-output draft review, activation readiness, handoff, and flow
review, but not preservation/replay or execution-record preparation.

PR #244 added repository-local activation-flow fixture and replay tooling. It
lets operators save and replay safe activation-flow evidence without raw hosts,
ports, URLs, credentials, raw logs, tokens, subscription URLs, YAML, approval
phrases, execution routes, subscription-output mutation, edge-node contact,
runtime deployment, traffic movement, or production activation.

PR #245 added repository-local activation execution-record template tooling.
It converts safe activation-flow fixtures into Markdown skeletons for later
exact-approved A-tier subscription-output activation records, with TODO
sections for approval reference, preflight, activation, validation, rollback,
and not-performed evidence.

PR #246 exposed the same record-template conversion through a protected Admin
platform route. This connected the template generator to the protected API
surface while keeping the response advisory: no approval submission, execution
controls, YAML generation, subscription-output mutation, edge-node contact,
runtime deployment, traffic movement, or production activation.

PR #247 connected the protected record-template route into Admin Overview. The
operator can now paste a safe activation-flow fixture, review the suggested
execution-record path, skeleton title, Markdown preview, readiness state, and
no-mutation safety flags, and the UI blocks obvious raw subscription URL/token
material before calling the protected route.
