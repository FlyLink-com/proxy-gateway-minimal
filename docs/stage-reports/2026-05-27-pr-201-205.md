## What Changed And Why

PR #201 added the cadence report for PR #195-#200 and preserved the project
operating-model requirement that each merged PR window has a durable summary.

PR #202 added the clean edge node rebuild runbook and execution template. It
separated clean edge data-plane rebuild from the current Aliyun subscription
control/distribution host, HP operator lab, and the stopped AWS rollback-start
path. It requires a future exact approval phrase before any clean host
provisioning, bootstrap, secret injection, or private edge validation.

PR #203 aligned channel documentation with the current Aliyun subscription
boundary and stopped AWS edge state. It added the TUIC Stage 0 read-only
inventory handoff after the held Hysteria2 measurement. The handoff is
inventory-only and does not authorize TUIC deployment, server creation, port
exposure, subscription output changes, operator-device traffic, or cleanup
mutation.

PR #204 added the opaque artifact issuance and legacy query-token retirement
runbook plus two execution templates. It deliberately split broader artifact
issuance from legacy query-token retirement and kept future route removal as a
separate compatibility gate.

PR #205 exposed the new artifact-migration gates through the protected Aliyun
gate decision packet. It added fail-closed Admin metadata for broader opaque
artifact issuance and legacy query-token retirement, while preserving no
approval submission route and no execution controls.
