# Documentation Index

Last updated: 2026-06-13, Asia/Shanghai.

Use this file as the first navigation point for project documentation. It
classifies current source-of-truth docs, active runbooks, execution records,
and compact archive pointers. It does not authorize production, AWS, DNS, Nginx,
HTTPS, deploy, secret, token, subscription URL, SQLite, or customer-data actions
by itself.

The active reading path should stay current-first. Old specs, plans, paused
runbooks, and fixed-cadence reports belong under `docs/archive/` with index
pointers instead of competing with current runbooks in the root docs directory.
Before importing anything from old local checkouts, worktrees, archive
directories, generated artifacts, or release packages, read
`docs/CURRENT_SOURCE_AND_ARCHIVE_BOUNDARY.md` and keep current source,
historical reference, and runtime material separated.
