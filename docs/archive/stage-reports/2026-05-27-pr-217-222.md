## What Changed And Why

PR #217 added the channel runtime evidence bridge and CLI. It converts safe
runtime evidence packets into runtime inventory input and a full channel system
decision artifact without contacting nodes, running probes, deploying runtimes,
or mutating subscription output.

PR #218 recorded a fresh read-only Aliyun Aegis repair preflight after repeated
short confirmations that were not exact A-tier approval phrases. It preserved
forward movement by recording current Aegis and subscription-boundary evidence
without repair mutation.

PR #219 added protected Admin API/UI support for channel runtime evidence
review. It also hardened the bridge after review so runtime evidence, dry-run
summary, and measurement-score inputs reject endpoint-shaped labels or values
instead of echoing them.

PR #220 recorded the exact-approved Aliyun Aegis service repair execution. The
repair failed but stopped safely: reset/start and Aegis-only process cleanup
were attempted, stuck Aegis/AliYunDun processes could not be terminated within
the gate, and `aegis.service` remains failed. The subscription boundary and
out-of-scope systems stayed safe.

PR #221 added the channel runtime gate workbench service, protected API route,
and Admin Overview panel. It turns safe runtime bridge packets into gate-facing
advisory status, counts, approval-readiness metadata, and grouped candidates
without approval submission or runtime execution controls.

PR #222 recorded the clean edge data-plane rebuild preflight. It captured
AliDNS and Aliyun remote-vantage evidence after Aliyun subscription promotion,
confirmed the old AWS edge address is not serving, confirmed stopped AWS edge
nodes have no public IP association, and recorded that no clean edge target has
been selected or provisioned.
