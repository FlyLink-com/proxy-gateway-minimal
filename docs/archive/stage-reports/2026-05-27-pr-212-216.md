## What Changed And Why

PR #212 added the repository-local channel system decision flow. It composes
safe dry-run summaries, measurement scores, runtime inventory input, runtime
registry output, and runtime gate packets into one advisory readiness artifact.
It does not run probes, contact edge nodes, deploy runtimes, change traffic, or
alter subscription output.

PR #213 added the previous #206-#211 cadence report and updated the docs index
plus project context pointer. It did not authorize runtime, DNS, firewall,
artifact issuance, legacy-token retirement, channel deployment, or edge
activation.

PR #214 exposed the channel system decision flow through a protected Admin
platform route. The route accepts already-collected safe channel evidence and
returns the same redacted advisory readiness artifact as the local builder.

PR #215 added the Admin Overview channel system review panel. Operators can
paste a safe evidence packet, review redacted readiness output, and rely on
client-side unsafe-evidence blocking before protected API submission.

PR #216 added the access model inventory summary contract and CLI. It provides
a safe way to normalize operator-provided counts, booleans, and labels into
artifact-issuance preflight evidence while rejecting raw URLs, secrets, tokens,
credentials, customer data, and SQLite rows.
